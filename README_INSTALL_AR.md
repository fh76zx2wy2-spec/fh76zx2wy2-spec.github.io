# 45/4 — إصلاح مكتبة البدائل ورسوماتها وشروحاتها

## ماذا تغير؟
- تحديث خيارات البدائل بالاعتماد على العضلة الأساسية ونمط الحركة؛ فصل الفيس بول عن الرفرفة الخلفية، وفصل دفع الترايسبس للأسفل عن الديبس والتمديد فوق الرأس، وإبعاد تمارين الجذع المختلفة عن كونها بدائل مكافئة تمامًا.
- إضافة رسومات SVG متجهية لكل بديل مفقود، بنفس درجات لون رسوم 45/4. الرسوم تختلف بحسب الجهاز (كيبل، دمبل، سميث، بار، جهاز)، مع عنوان صغير يميز الشكل. ليست صورًا فوتوغرافية وليست بديلًا عن تعليمات الضبط الخاصة بكل موديل جهاز.
- توحيد عرض الرسم في شاشة اختيار البديل وشاشة أداء التمرين ودليل الأجهزة وصفحة تفاصيل الجهاز.
- تصحيح تكرار مقطع واحد على عدة بدائل: شروحات يوتيوب المحددة تُعرض داخل الموقع فقط عندما يتوفر مقطع معروف مطابق لاسم التمرين، ولكل بديل رابط مستقل. لبقية البدائل يُعرض الشرح العربي والرسم أولًا مع زر بحث يوتيوب مخصص باسمها الحقيقي؛ لا يعرض الموقع فيديوًا خاطئًا على أنه لبديل آخر.
- إضافة نافذة شرح مستقلة في دليل الأجهزة، بالإضافة إلى شاشة التمرين، وتبقى ذاكرة الوزن واختيار الجهاز كما هما.

## تركيب التحديث
1. فك ملف ZIP.
2. افتح GitHub Desktop ثم Repository → Show in Explorer لمستودع `fh76zx2wy2-spec.github.io`.
3. انسخ مجلد `src` من هذا التحديث إلى المستودع ووافق على استبدال الملفات الستة المحددة داخله فقط. **لا تمسح أي ملفات أخرى.**
4. GitHub Desktop → Summary: `تصحيح رسومات وفيديوهات بدائل الأجهزة` → Commit to main → Push origin.
5. بعد النشر أعد فتح الموقع من أيقونة الشاشة الرئيسية أو أغلقه وافتحه للحصول على ملفات النسخة الجديدة.

## لا تحتاج Supabase
هذا التحديث ملفات واجهة/مكتبة تمارين فقط، ولا يتطلب SQL أو تعديل Edge Function أو Cron أو Secrets. بيانات الزيارات والعضوية والخصوصية والإشعارات محفوظة.

## فحص المحتوى
- فُحص تحليل ملفات TypeScript الستة دون أخطاء تركيبية.
- فُحصت 20 مجموعة بدائل، وأن جميع الخيارات الـ92 المشار إليها موجودة في مكتبة 109 تمارين/أجهزة، مع وجود خطوات شرح لكل تمرين.
- جرى فحص عدم تكرار روابط فيديوهات يوتيوب المُعتمدة داخل المكتبة.
- تعذر اختبار build كامل لعدم توافر حزم npm المطلوبة في بيئة الإنشاء؛ لذلك يُفضّل مراجعة نتائج GitHub Actions / Pages بعد النشر. الروابط الخارجية قد تتغير بقرار من مالك الفيديو.
