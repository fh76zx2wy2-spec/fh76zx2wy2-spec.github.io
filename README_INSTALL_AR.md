# 45/4 — استعادة خياري مشاهدة التمارين

## التغيير
- نافذة شرح الجهاز تعرض خيارين واضحين دائمًا: «مشاهدة الفيديو داخل الموقع» و«مشاهدة نفس الفيديو على يوتيوب» عندما يتوفر رابط فيديو محدد.
- الخياران يشغلان *نفس الفيديو المحدد*، وليس مقطعًا واحدًا لأجهزة مختلفة. التشغيل الداخلي لا يبدأ حتى تضغط زر المشاهدة.
- أضفنا 7 روابط مطابقة جديدة للأجهزة/البدائل، مع الحفاظ على روابط النسخة السابقة.
- في البدائل التي لم يُعتمد لها فيديو محدد، يظهر بدلًا من زر الفيديو «عرض الشرح المصور داخل الموقع»، ورابط نتائج يوتيوب باسم البديل الصحيح. لا ندعي وجود مقطع داخلي غير موجود.
- نفس النافذة تعمل من «تمريني اليوم» ومن «دليل الأجهزة». باقي الموقع لم يتغير.

## التركيب
**ركّب هذا التحديث فوق تحديث البدائل والرسومات بتاريخ 16 أكتوبر 2026**؛ لأنه يعتمد على مكوّن ExerciseVideoGuide الذي أضافه ذلك التحديث.
1. فك الضغط.
2. افتح GitHub Desktop > Repository > Show in Explorer.
3. انسخ مجلد `src` إلى جذر المستودع واختر دمج المجلدات واستبدال الملفين فقط (`ExerciseVideoGuide.tsx` و`machines.ts`). لا تحذف أي ملفات أخرى.
4. Commit to main > Push origin.
5. Summary: `استعادة المشاهدة داخل الموقع وعلى يوتيوب للتمارين`.

لا يحتاج هذا التعديل SQL أو Edge Functions أو تغيير إعدادات الإشعارات.
