موقع 45/4 — تحديث v1.9.1: شاشة "ما الجديد؟" + جميع إضافات v1.9.0
=================================================================

هذا تحديث تراكمي يركَّب فوق v1.8.0 أو v1.9.0. لا يحذف الأعضاء أو الصور أو الأوزان أو الزيارات.

ماذا يُضيف؟
- مربع "تم تحديث التطبيق 🥰 v1.9.1" ثابت دائمًا في شاشة الدخول.
- نافذة «وش الجديد في التطبيق؟» ظاهرة بخط عريض وواضح عند أول فتح لكل عضو بعد الإصدار.
- إغلاقها مرة واحدة يمنع تكرارها للإصدار نفسه، وتظهر مجددًا لإصدار جديد فقط.
- تسجل قاعدة البيانات أن صاحب الحساب قرأ ملخص الإصدار؛ يتزامن عبر أجهزته عند اتصال الإنترنت.
- يحفظ المتصفح الحالة محليًا أيضًا إذا فقد الإنترنت؛ إذا تعذّر تثبيت جدول SQL فلن يتزامن الإقرار بين الأجهزة.
- قائمة الميزات: رياضة أخرى، احتساب 4/4، الإشعارات الذكية، الخصوصية، شاشة التحديث.
- يظل زر «دخول» وصورة الكوتش وتصميم الشاشة كما كانا.

الخصوصية والإشعارات (من إصدار v1.9.0 المرفق)
- جميع الأعضاء النشطين (بمن فيهم أي عضو جديد) يُعالَجون ديناميكيًا.
- زياد يرى الجميع ويصله نشاط الأعضاء.
- عبدالسلام/ضيدان/أي عضو آخر يرى نفسه وزياد فقط، ولا تصل إليه إشعارات باقي الأعضاء.
- كل عضو جديد يحتاج إلى تفعيل إشعارات جهازه مرة واحدة، لا بعد كل تحديث.
- لا تُحدَّث أي سجلات في push_subscriptions في SQL هذا الإصدار، ولا تُمسح رموز VAPID أو cron.
- ملاحظة: الاشتراك يمكن أن يتوقف خارج الموقع بسبب إعدادات الهاتف؛ نجاح كود الإرسال لا يضمن التسليم الفعلي دون تجربة.

التثبيت:
(أ) إذا كان v1.9.0 مُطبقًا بالفعل (SQL + Edge Function + GitHub):
    1. افتح supabase/45-4-v1.9.1-RELEASE-READ-ONLY-ADD.sql وأجره مرة واحدة في SQL Editor.
    2. انسخ مجلد src في ZIP إلى جذر مستودع GitHub، دمج واستبدال الملفات المطابقة فقط.
    3. GitHub Desktop → Commit to main ثم Push origin.
    لا تحتاج إعادة نشر Edge Function لأنها لم تتغير في v1.9.1.

(ب) إذا كان الموقع ما يزال v1.8.0 (مثل الصورة المرسلة):
    1. نفّذ supabase/45-4-v1.9.0-SPORTS-SAFE.sql أولًا.
    2. نفّذ supabase/45-4-v1.9.1-RELEASE-READ-ONLY-ADD.sql بعده.
    3. استبدل Edge Function المسماة push-45-4 بكود supabase/push-45-4-v1.9.0.ts ثم Deploy updates.
       لا تغيّر Cron أو Secrets أو VAPID_PUBLIC_KEY أو VAPID_PRIVATE_KEY.
    4. انسخ مجلد src في ZIP إلى مستودع GitHub، مع الدمج فقط، ثم Commit وPush.
