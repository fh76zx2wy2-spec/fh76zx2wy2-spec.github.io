تحديث موقع 45/4 — الإصدار v1.8.0
===================================
هذا التحديث مخصص للتركيب فوق الإصدار 1.7.0 الذي سبق تثبيته.

طريقة التركيب
1) فك ضغط الحزمة.
2) افتح مجلد المستودع في GitHub Desktop → Repository → Show in Explorer.
3) انسخ مجلدي src و public إلى جذر المستودع مع استبدال الملفات المتطابقة.
4) في Summary اكتب: تحديث 45/4 v1.8.0 – أجهزة أساسية ورسومات جديدة وتحسين شاشة الدخول
5) Commit to main ثم Push origin.

أبرز التغييرات
- أجهزة النادي الفعلية أصبحت ضمن تمارين الحديد الأساسية في الأيام المناسبة، لا ضمن بطاقة إضافية أسفل اليوم.
- صور الأجهزة الفوتوغرافية التي أرسلتها استُبدلت برسومات SVG مبسطة مستقلة ومرنة الحجم.
- عرض بطاقة «تم تحديث التطبيق 🥰» بشكل أكبر وأوضح، ورقم الإصدار 1.8.0.
- مدة 45 دقيقة هدف تقريبي، لا حد أقصى لعدد الأجهزة أو مدة أداء تمارين الحديد.
- بقيت تمارين المقاومة 5 دقائق مقترحة لكل يوم، وبقيت شروح الأجهزة والفيديوهات السابقة.

التوزيع
اليوم 1 (علوي أ): جهاز البايسبس أساسي مكان بايسبس الدمبل.
اليوم 2 (سفلي أ): تمديد الفخذ الأمامي + السمانة واقف + كرنش البطن أجهزة أساسية؛ والخلفي جلوس موجود أساسًا.
اليوم 3 (علوي ب): فراشة الصدر جهاز أساسي.
اليوم 4 (سفلي ب): فتح الورك للمؤخرة الجانبية + الفخذ الخلفي مستلقيًا جهازان أساسيان.
ملاحظة: صور الفخذ الخلفي جلوس والبايسبس وزوايا الجهاز المكررة لم تتحول إلى تمارين متكررة.

حماية بياناتك وإشعارات الأعضاء
- لا توجد أي ملفات SQL أو تغييرات بقاعدة البيانات.
- لا تعدّل الحزمة Supabase أو العضويات أو القواعد أو التسجيل أو الإشعارات أو مفاتيحها أو Service Worker أو Cron أو Secrets.
- لا تُحذف أي زيارة أو سجل أوزان أو إشعار محفوظ. تمارين قديمة ستبقى في السجل بمفاتيحها القديمة.
- إن كانت هناك جلسة جارية، فمراحلها المحفوظة تبقى كما كانت حتى إكمالها؛ تظهر تمارين الأجهزة الجديدة عند بدء جلسة جديدة.
- لا ترفع هذا المجلد كمشروع جديد، بل انسخه داخل مستودع المشروع الحالي.
- الرسومات الحالية توضيحية مُبسطة وليست نسخًا هندسية مطابقة للأجهزة. يرجى الرجوع إلى ملصقات الضبط على الأجهزة نفسها.

لا داعي لإعادة تفعيل الإشعارات. هذا التحديث لا يطلب ذلك.
